# Installing Devouring Storms

## Java Edition (26.2)

1. Install **Fabric Loader 0.19.3+** for Minecraft 26.2.
2. Download **Fabric API 0.156.0+26.2** into your `mods/` folder.
3. Build the mod (see `docs/BUILDING.md`) and drop
   `java-mod/build/libs/devouring-storms-<version>.jar` into `mods/`.
4. Launch. Create a world. **The blueprints are already out there.**

### Optional: the full storm look
Install **Iris + Sodium**, then put `shaders/DevouringStormsShaderPack` (zipped) into
`shaderpacks/` and select it in Video Settings.

## Bedrock (26.40, all platforms incl. Realms)

1. Zip each of `bedrock-addon/DevouringStormsBP` and `bedrock-addon/DevouringStormsRP`
   and rename the zips to `.mcpack` (or pack both folders into one `.mcaddon`).
2. Open the packs with Minecraft to import them.
3. New world → **Experiments: OFF (not needed)** → Resource Packs: activate
   *DEVOURING STORMS — Resource Pack* → Behavior Packs: activate
   *DEVOURING STORMS — Behavior Pack*.
4. Enter the world:
   - The Decayed Realm replaces the End dimension's ambience with fog, watchers and symbionts.
   - Build the ritual: Corrupted Command Block + Corrupted Blueprints → the Signal begins.

## Your first night

1. Find the **Corrupted Blueprints** (Ancient City / Stronghold chests).
2. Craft the **Corrupted Command Block** (recipe: wither skulls + crying obsidian + nether star).
3. Place it, touch the blueprints to it. **MASSG IS WAKING UP.**
4. Feed it nothing. Understand that it will feed anyway.
5. Craft a **Terminal** and a 5×5 **Mainframe** foundation; earn a **Rift Key**
   (Watcher Eye + Memory Fragment + amethyst + storm dust).
6. Breach the Mainframe. Enter the Decayed Reality. Meet **Tazo**. Don't look at the Watcher.
7. Return with **storm materials**, craft the **Formidibomb**.
8. Kill it. **Watch it play dead.** Use the Formidibomb. **END IT.**
